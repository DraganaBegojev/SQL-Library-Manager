# SQL Library Manager


A simple CRUD (Create, Read, Update, Delete) app built with Express.js, Sequelize ORM, and Pug templates.
This project is part of the Treehouse Full Stack JavaScript Techdegree, demonstrating skills in server-side programming, database integration, form validation, and UI rendering.

🚀 Features

✅ View a list of all books in the library
✅ Add new books using a form
✅ Edit or delete existing books
✅ Search books by title, author, genre, or year
✅ Pagination for easy navigation when the list grows large
✅ Server-side form validation with friendly error messages
✅ Graceful handling of 404 and 500 errors

🧠 Technologies Used

- Node.js & Express.js – server and routing

- Sequelize – ORM for database interaction

- SQLite – database (development)

- Pug – template engine for views

- CSS – simple styling for clean layout
